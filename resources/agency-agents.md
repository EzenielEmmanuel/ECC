## Findings
A library of specialist agent definitions and workflows covering engineering, design, marketing, testing and other functions. Requires a host AI tool/model; it does not supply model weights or free inference. Upstream documents integrations for OpenCode, OpenClaw, Hermes, Codex and others.

## Proposed ORIS use
Evaluate a small frontend, backend and review roster within ORIS-Code. This could supply reusable specialist instructions while ORIS handles models, memory, orchestration and permissions. Hosting and model costs remain separate.

## Next evaluation
Review selected definitions and installer scripts; pin a commit; test one bounded development task. Compare quality, token usage and permissions before expansion. Upstream currently warns of an OpenCode agent-registration limit; install a small subset.
