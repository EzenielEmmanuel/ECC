# Source Oneness Creation Resource Factory (SOCRF)

## Purpose
An independent, modular, AI-powered production resource factory for designing, building, testing, deploying, operating, and improving sophisticated digital products and human-centered platforms at the highest practical standard.

**Guiding principle:** Creative sovereignty through intelligent infrastructure.

## Foundation
This development branch is based on the upstream Everything Claude Code (ECC) project. Preserve upstream history, attribution, licensing and the ability to incorporate future upstream changes. This document establishes our internal development direction, not a claim of original authorship of ECC.

## Roadmap
1. Inventory ECC's agents, skills, commands, hooks, dependencies and installation workflows.
2. Establish a safe, isolated cloud test environment with least-privilege credentials.
3. Run baseline tests and document reproducible setup.
4. Add resource registry, modular tool adapters, and governance controls.
5. Integrate specialized coding, research, design, media and deployment capabilities as needed.
6. Benchmark quality, reliability, cost and security against real platform-development tasks.

## Product focus
SOCRF is internal infrastructure, not a generic AI model to repackage. Its purpose is to enable ambitious human-centered platforms including KEYS, HotWavz Plus and future creations.

## Change policy
Develop changes on dedicated branches, test before merging, keep secrets out of the repository, respect third-party licenses and avoid uncontrolled agent access to production resources.
